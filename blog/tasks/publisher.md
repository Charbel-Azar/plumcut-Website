# Moved

The writer and the publisher are one job now. **Read `blog/tasks/author.md` and
follow it exactly.** It is the full procedure and the single source of truth for
this run.

That file takes a post from subject to live in a single run: read the control
page, mine the meetings, find the question the market asks around the subject,
write it, review it, build, push, verify, log. There is no drafting stage and no
approval stage any more.

This page exists only so a routine still pointed here lands in the right place.
Do not write a post from what you remember of the old writer procedure.
